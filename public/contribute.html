How to help grow Mindset Bucket without breaking the lake.

Repository

The code lives at github.com/collective-bucket/mindset. Fork, open a branch, and send a pull request against main.

Stack limits

Static Firebase Hosting on the Spark plan only. No Cloud Functions, no paid AI APIs. Scoring stays in the browser.

Language

Source and commits stay in English. UI strings may be Turkish. Add both EN and TR keys in i18n.js when you touch copy.

Closed texts

Never put closed field text into public documents, lists, or the DOM for strangers. Teasers and locks only.

Before you push

Run npm run check. Keep firestore.rules ads/trips untouched unless the change is required and reviewed.
